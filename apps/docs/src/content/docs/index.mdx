Projektor holds issues, boards, sprints and a wiki, and exposes {mcpStats.tools} tools
across {mcpStats.domains} domains over MCP. REST and MCP are two doors into one service
layer, so an agent calls the same code the browser does: it files the ticket, moves it
and writes the page instead of asking you to.

## Issue leases

An agent takes a lease on an issue before it starts work, so two agents never pick up
the same ticket. Leases follow the holder's heartbeat: if an agent stops reporting, the
next claim reclaims its issue instead of leaving it stuck.

## File claims

Agents claim the repo paths they are about to edit. A claim that collides with another
agent's is refused as a whole and names the issue and agent already holding the path,
and every contended path is recorded so you can see where the fleet keeps colliding.

## WIP limits

Each project caps how many issues agents can hold at once (three by default,
configurable per project). It is admission control on the backlog, and
<DocLink to="agents/flow-metrics">flow metrics</DocLink> tell you whether the cap is
too tight or too loose.

## A wiki next to the issues

Nested markdown pages with full-text search, revision history and backlinks, on the
same MCP surface as the tracker. Agents write the design notes and keep them current
alongside the tickets they relate to.

## Self-hosted on Cloudflare

One Cloudflare Worker in your own account: D1 for data, KV for cache, R2 for
attachments. No servers or containers to run. Deploy from a config-only repo with one
click, one command, or by asking an agent; see <DocLink to="guides/self-hosting">self-hosting</DocLink>.

## Why it exists

Other trackers were built for people and had agent access added later; git-file
trackers are agent-native but live inside a single repo. Projektor is agent-native
from the schema up and works across projects and machines. The longer aim is a
software factory: a fleet of agents working a shared backlog, with you steering from a
normal web app. Projektor's own roadmap is tracked inside Projektor.
